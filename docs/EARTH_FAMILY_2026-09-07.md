# Student and family Earth inquiry companion

The existing Now/opening window, calendar, portfolio and required learning remain unchanged. A new optional card appears only after the Students, Families and Learning views. It links to a local, independent five-minute conversation using an ordinary object already at hand.

The companion contains no embedded teacher lesson data or answer keys. Film links are optional adult-preview choices, not independent student assignments. There are no required accounts, purchases, donations, petitions, uploads or disclosures of family spending or circumstances.

Teacher Hub supplies a single canonical authoring source. The build uses a pinned commit and checks the exact Git blob hashes before execution. Only the family HTML is written into public output; source caches stay outside public/ and are ignored by Git. Published use never fetches Teacher Hub.

Branch-only review runs the existing repository tests and checks the actual built family asset. Report completion and deployment separately. No classroom trial or full streaming/caption verification is claimed.
